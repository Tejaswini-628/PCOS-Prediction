# 🧠 PCOS Prediction using Machine Learning

## 📌 Project Overview
Polycystic Ovary Syndrome (PCOS) is a common hormonal disorder affecting women of reproductive age. Early detection is crucial for timely medical intervention.  

This project implements a **PCOS prediction system using Machine Learning**, where a **Random Forest classifier** predicts the likelihood of PCOS based on clinical and lifestyle features.

The system also includes a **web-based interface** for user interaction and real-time predictions.

---

## 🚀 Features
- PCOS risk prediction using Machine Learning
- Random Forest ensemble model for high accuracy
- User-friendly web interface
- Backend API for model inference
- Scalable and extendable architecture

---

## 🧠 Machine Learning Model
- **Algorithm Used**: Random Forest Classifier  

**Why Random Forest?**
- Handles non-linear relationships effectively  
- Reduces overfitting using ensemble learning  
- Works well with mixed numerical and categorical data
